# Personal diary

A simple public diary website, hosted with GitHub Pages.

## Add an entry

Edit `index.html` and replace the “No entries yet” paragraph with diary entries. Put the newest entry first. For example:

```html
<article>
  <h3><time datetime="2026-11-04">November 4, 2026</time></h3>
  <p>Write your entry here.</p>
</article>
```

You can add more paragraphs, lists, or links inside an `<article>`. Commit your changes to `main`; GitHub Pages can publish the site from the repository's main branch.
